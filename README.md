GoldBrain is a discontinued experimental project by twin brothers Bardiya and Armiya Alizadeh (Kabir). It combines a Persian-first Flutter interface with a Python/FastAPI backend. The source is preserved so another developer can understand the work, reproduce the current state and decide how to continue it.

Co-creators: **Bardiya Alizadeh (Kabir) · Farland_game** and **Armiya Alizadeh (Kabir) · ArmiyaFbix**, credited equally in the project's latest About screen and development notes.

Bardiya describes roughly seven months of work, beginning with little programming experience and learning through experimentation, online resources and AI assistance. The original ambition was a Windows/Android product with short- and long-horizon market predictions, followed by automated Wallex trading using only a user-selected portion of their funds. He stopped pursuing that full vision because of its infrastructure requirements, costs, complexity and financial risk. These were goals, not completed or validated capabilities.

> The brain had big plans. The infrastructure invoice had plans of its own. 🧠🧾😅

## What the preserved source contains

- A custom Flutter interface with 11 themes, 8 existing interface languages, animation, charts, settings, watchlists, audio controls and an About page.
- A FastAPI backend with normalized market quotes/history, provider provenance, freshness and quality checks, persisted overview data and a collection worker.
- A research forecasting engine with features, chronological evaluation/backtesting and evidence records; this is distinct from the unfinished final predictor.
- Simulated paper-trading APIs; the visible portfolio UI and real-money trading are not complete.
- Email-verification/password-reset flows, Argon2 passwords, JWT access tokens, refresh rotation and device/session controls.
- RSS news, optional AI article translation/summaries, a bounded read-only chat assistant and a six-country market pulse.
- Backend and Flutter test sources, ten database migrations, configuration examples, architecture/API documents and historical progress/decision records.

## Where the work stopped

- The planned Phase 6 live/self-feedback prediction system is unfinished. Its assistant tool explicitly reports unavailable rather than inventing a forecast.
- Automatic real-money Wallex trading and the proposed user-budget allocation workflow were not implemented. The exchange adapter is a mock contract.
- Production-grade data agreements, independently validated financial performance, public deployment hardening and reliable provider access remain open work.
- Payment processing, a complete portfolio UI and some visible settings are unfinished. A subscription/entitlement model is not a completed checkout system.
- The current integrated source has Windows and web scaffolds; the older Android scaffold is preserved separately. A working current Android or web release has not been verified.
