# Optional bundled audio

The original audio is supplied separately in the `GoldBrain-audio-assets.zip` release asset. Restore it with `python scripts/restore_audio.py --archive <downloaded-zip>` before expecting bundled music/effects or opting into native audio smoke tests. Normal source builds can be made without these recordings; bundled playback will be unavailable. Custom tracks require your own permitted local files.

The creator confirmed permission to redistribute the supplied recordings. Their own rights/terms remain separate from the source-code license. See `docs/ASSETS_AND_LICENSES.md` and `audio-manifest.json`.
