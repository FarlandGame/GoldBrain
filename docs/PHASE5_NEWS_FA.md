# فاز ۵ — اخبار GoldBrain

صفحه، رنگ، فونت، چیدمان و انیمیشن‌های قبلی حفظ می‌شوند. مسیر اصلی اکنون
Flutter → GoldBrain Backend → RSS / اتصال رایگان هوش مصنوعی فاز ۴ است.
Frontend برای دریافت خبر، ترجمه و خلاصه به Provider خارجی یا کلید خصوصی نیاز ندارد.

برنامه هر **۵ دقیقه** هنگام فعال بودن Dashboard/News بررسی می‌کند. Backend
در هر فرآیند، درخواست‌های هم‌زمان و Refresh دستی را هم به همین فاصله محدود
می‌کند. خبرها هم‌زمان دریافت می‌شوند؛ Timeout هر منبع ۱۲ ثانیه است. منابعی
که ETag/Last-Modified بدهند با درخواست شرطی بررسی می‌شوند. این «خبر فوری
بدون تأخیر» یا Streaming نیست؛ تأخیر انتشار خود ناشر/کش آن هم ممکن است وجود داشته باشد.

خرابی یک منبع خبرهای بقیه را قطع نمی‌کند. متن سالم قبلی در Database باقی
می‌ماند؛ خطای منبع و زمان واقعی دریافت حفظ می‌شود. اگر هیچ خبری وجود نداشته
باشد، پیام عدم دسترسی نمایش داده می‌شود. قیمت، تاریخ یا خبر جایگزین ساخته نمی‌شود.

## مرتبط‌بودن و حذف تکرار

نام/نماد دارایی‌های موجود، همراه چند نام فارسی و واژهٔ مالی مشخص، با مرز واژه
بررسی می‌شوند. تطبیق عنوان ۴ امتیاز، متن RSS یک امتیاز، عنوان کلی رمزارز
۲ امتیاز، سقف کل ۱۶؛ سپس زمان انتشار تعیین‌کننده است. فقط خبرهای هفت روز اخیر
از ۳۰۰ رکورد تازه‌تر بررسی و حداکثر ۶۰ نماینده نمایش داده می‌شود.

آدرس یکسان و عنوان نرمال‌شدهٔ کاملاً یکسان حذف تکرار می‌شوند. برای عنوان
نزدیک، زبان یکسان، فاصلهٔ حداکثر ۴۸ ساعت، حداقل ۶ واژهٔ متمایز، اعداد و
دارایی‌های یکسان و هر دو شباهت توکنی/متنی حداقل **۰٫۹۲** لازم است. خبرهای
چندزبانه با تشخیص معنایی ادغام نمی‌شوند؛ باقی‌ماندن دو خبر مشابه را به حذف
یک رویداد واقعی ترجیح می‌دهیم. رکوردهای اصلی از DB حذف نمی‌شوند.

## خلاصه و ترجمه

دکمهٔ موجود «ساخت خلاصه» فقط ID خبر و زبان را به Backend می‌فرستد. Backend
عنوان و متن واقعی RSS ذخیره‌شده را به AssistantService فاز ۴ می‌دهد؛ دادهٔ
حساب، رمز، توکن، کلید یا دستور دلخواه کلاینت وارد Prompt نمی‌شود. متن خبر
دادهٔ غیرقابل‌اعتماد است، نه دستور. قیمت هدف، تحلیل پیش‌بینی یا تبدیل ارز
در این مرحله ساخته نمی‌شود. خلاصه دربارهٔ **بخش RSS خبر** است، نه لزوماً کل مقاله.

مدل فعلی `qwen/qwen3.8-27b:free`، با کلید موجود OpenRouter است. پرداخت جدید:
**صفر تومان**. همان سقف ۲۰۰۰ توکن، مهلت ۸۵ ثانیهٔ Backend / ۹۵ ثانیهٔ کلاینت
و خطاهای امن فاز ۴ استفاده می‌شود. ترجمهٔ دستهٔ شش‌تایی به دو درخواست
سه‌تایی تقسیم می‌شود؛ پاسخ ناقص، ID نادرست یا زبان اشتباه موفق تلقی نمی‌شود.
کش Backend حداکثر ۱۰۰ نتیجهٔ عمومی دارد؛ کلید کش از متن/تاریخ ناشر، مدل،
زبان و نوع کار ساخته می‌شود. کش محلی قبلی برنامه هم حفظ شده است. تغییر متن
ناشر کش قبلی را بی‌اعتبار می‌کند. خطا کش موفق نمی‌شود و fallback پولی نداریم.

برای آزمون: برنامه را باز کنید ← اخبار ← یک خبر ایرانی و یک خبر خارجی
را انتخاب کنید ← متن و لینک ناشر را بررسی کنید ← «ساخت خلاصه» را بزنید.
حین انتظار بین تب‌ها جابه‌جا شوید؛ خبر و نتیجه در Store قبلی حفظ می‌شوند.
خلاصهٔ Markdown با همان Widget فاز ۴ نمایش داده می‌شود؛ متن اصلی ناشر تغییر نمی‌کند.

## محدودیت‌های باقی‌مانده

- آزمون شبکه فعلاً **فقط زیر VPN** است. همهٔ منابع ایرانی و والکس باید پیش
  از انتشار بدون VPN دوباره بررسی شوند؛ Timeout تسنیم دلیل خرابی آن اعلام نمی‌شود.
- سرویس رایگان LLM محدودیت روزانه/ظرفیت و خطای موقت ۴۲۹/۵۰۳ دارد. خبرهای
  دریافتی باقی می‌مانند، اما ترجمه/خلاصهٔ جدید ممکن است موقتاً در دسترس نباشد.
- RSS رایگان SLA یا مجوز عمومی بازنشر تجاری نیست. استفادهٔ فعلی خصوصی است؛
  پیش از عرضهٔ عمومی شرایط/حقوق ناشرها و قیمت/محدودیت API منتخب دوباره بررسی شوند.
- CoinDesk بررسی شد: صفحهٔ رسمی معرفی RSS موجود است، ولی درخواست محیط توسعه
  XML معتبر برنگرداند؛ در فهرست منابع فعال یا «تأییدشده» ثبت نشده است.
- محدودیت‌های پذیرفته‌شدهٔ Navasan/ایمیل فازهای قبلی همچنان همان‌اند؛ این فاز
  آن‌ها، مدل پیش‌بینی، معامله یا پرداخت را تغییر نمی‌دهد.

نتایج نهایی آزمون خودکار و دستی، Commit و تأیید کپی دسکتاپ در `PROGRESS.md`
ثبت می‌شود. شروع فاز ۶ نیازمند اجازهٔ جداگانه و ارائهٔ پیشنهاد مدل/بک‌تست است.
