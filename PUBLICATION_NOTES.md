# Preservation publication — 2026-11-01

GoldBrain's original source and project documentation are released under the root MIT License, with Bardiya and Armiya Alizadeh (Kabir) credited together. Bardiya selected MIT explicitly for publication of their shared source. The historical in-app notice prohibits **unauthorized** redistribution; the new MIT grant supplies permission for the original code/documentation covered by that grant. The historical application text is preserved, not silently rewritten.

Third-party libraries, platform templates, recordings, provider content and other third-party material retain their own terms. In particular, the separate audio pack is supplied on the creator's explicit statement that redistribution is permitted; no claim is made that the code's MIT grant relicenses every recording. See [asset notices](docs/ASSETS_AND_LICENSES.md).

This is a source-preservation and continuation release, not a completed financial product or a new validation of its prediction performance. The planned final predictor and automatic real-money Wallex trading remain unfinished. No original application source, tests or local account data were repaired or changed to make the project appear complete.

Added publication material consists of the multilingual portfolio introduction, current status/setup/continuation/verification/version guides, license and provenance records, an optional audio restore helper and adjusted ignore rules. The original README remains at [docs/history/README.original.md](docs/history/README.original.md). Existing technical/development records retain their historical context. See [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json) for preserved source hashes.

Private environment files, account/test databases, database backups, signing identities, private Git objects, caches/build outputs and unrelated local output folders are excluded. Older useful source snapshots are separate, explicitly dated release assets. The historical September Windows binary is not represented as a build of the current October full-stack source.

The user requested less memory usage during verification. The Flutter unit/widget suite was interrupted to free local RAM; its partial progress is not a complete passing result. Backend tests and Flutter static analysis have their own completed results in [docs/VERIFICATION.md](docs/VERIFICATION.md).
