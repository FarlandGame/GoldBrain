# Historical GoldBrain opening-animation source

The creator identified folders named GoldBrain as project material. This folder preserves the supplied Blender file and its `.blend1` backup from the opening-animation/design folder. Both are unchanged; hashes and sizes are in [PROVENANCE.json](PROVENANCE.json).

These are historical creative references, separate from the current Flutter/FastAPI source. They were not opened or rendered during this publication, and external Blender dependencies have not been checked. The original creators retain their creative rights; the code's MIT grant does not assert new rights over third-party creative elements. The supplied historical promo poster/video should not be taken as proof that every planned application feature shipped.
